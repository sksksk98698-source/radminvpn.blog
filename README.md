## 📖 项目简介 (Overview)

**radminvpn.blog** 是一套专为技术出海、网络工程、远程游戏联机以及跨境网络加速场景打造的高性能现代内容站点与商业级知识决策系统。

本项目深度结合 **Astro 5** 现代化静态站点构建器（SSG），采用**“双引擎驱动模式”**，彻底打通泛流量捕获与精准高意图决策转化：

1. **Radmin VPN 深度网络组网专栏**：围绕虚拟局域网（VLAN）、点对点 P2P 穿透、远程办公内网穿透与经典局域网联机游戏，提供专著级技术剖析与配置实战；
2. **全球网络加速与专线机场评测库**：收录并动态维护 **42 家主流机场品牌**、沉淀 **17 家晚高峰 4K 测速与流媒体解锁证据链**、全平台代理客户端（Clash Verge / Shadowrocket / sing-box）保姆级导入教程，以及全网独创的 **5 维跑路风险预警自救体系**。

## 🌟 核心特性矩阵 (Key Features)

### 1. 🔍 工业级 SEO & GEO 搜索引擎/生成式 AI 基础设施
- **主流爬虫 100% 深度兼容**：原生适配 `Googlebot`、`bingbot`、`Baiduspider`（百度）及 `yisouspider`（神马/UC/夸克），纯物理 HTML 直出，爬虫解析零阻碍；
- **双轨自动化 Sitemap**：提供 `/sitemap.xml` 与 `/sitemap-index.xml` 双端点输出，自动收录 294+ 规范页面，全自动剔除 API 分页碎片与无意义孤岛；
- **严格 Canonical 自引用矩阵**：全站坚决执行带尾斜杠（`Trailing Slash: always`）策略，阻断多 URL 权重稀释，杜绝大小写及重定向惩罚；
- **官方 JSON-LD Schema 结构化语义网**：
  - 首页：`WebSite` + `Organization` 企业级实体声明；
  - 核心专栏：`CollectionPage` + `BreadcrumbList` 多层级面包屑架构；
  - 42 家机场：标准化 `Review` + `Service` + `BreadcrumbList` + `FAQPage`，实体作者锚定为“Radmin VPN 技术团队”；
  - 正式博文：标准的 `Article` / `BlogPosting` 富媒体摘要；
- **多平台验证 Meta 零侵入预留**：内置 Google Search Console、Bing Webmaster、神马及百度站长验证机制，环境变量或配置文件一键注入。

### 2. 🏢 42 家机场品牌库与晚高峰实测证据链
- **动态数据集驱动**：结构化 JSON 集中治理 42 家主流品牌的基础协议、专线类型、入口分布与起步资费；
- **17 家晚高峰测速大图证据链**：实录 1122×1402 高清原始压测图，带节点测试时间戳、丢包率与 Netflix/Disney+ 4K 解锁实况；
- **精细化推荐与防踩坑机制**：针对主力推荐（光速云等）配置专属优惠码通道与线路质量深度评测。

### 3. ⚠️ 跑路预警与避险自救体系 (`/risk-alert/`)
- **5 维前兆识别体系**：涵盖突发大额折扣、工单响应迟缓、TG 禁言改单向、节点频繁红名、管理团队异常等核心风险维度；
- **42 家抗风险星级榜**：透明列出成立年限、专线架构底座与抗风险等级，为用户提供稳健老牌避风港；
- **突发跑路应急四步法**：详尽指导争议申诉、支付渠道追回、备用节点秒级切流与关键凭证存证。

### 4. 🎁 免费资源与开源工具全景导航 (`/free/`)
- 万字级真实可用正规免费工具库，汇聚 Radmin VPN、Tailscale、ZeroTier、WireGuard 等官方开源工具；
- 机场官方合规免费试用汇总与白嫖节点安全风险（钓鱼节点、数据嗅探、中间人攻击）深度解构。

### 5. ⚡ 极致性能与极致可访问性

## 🚀 快速开始 (Quick Start)

### 环境要求
- **Node.js**：`>= 18.20.0`
- **包管理器**：推荐使用 [pnpm](https://pnpm.io/) (`>= 8.0.0`)

### 1. 克隆代码仓库
```bash
git clone https://github.com/sksksk98698-source/radminvpn.blog.git
cd radminvpn.blog
```

### 2. 安装项目依赖
```bash
pnpm install
```

### 3. 启动本地开发服务
```bash
pnpm run dev
```
启动后访问控制台输出的本地地址（默认 `http://localhost:4321` 或 `http://localhost:4323`）。

### 4. 构建生产环境产物
```bash
pnpm run build
```
构建成功后将自动执行 `astro build` 生成 100% 纯静态 HTML/CSS/JS 到 `dist/` 目录，并自动触发 `pagefind` 离线搜索索引构建。

### 5. 本地预览生产构建
```bash
pnpm run preview
```

## ⚙️ 环境变量与生产配置 (Configuration)

您可以通过创建根目录 `.env` 文件，或在云端部署控制台配置以下环境变量：

```ini
# 正式线上站点绝对主域（必须以 https:// 开头，末尾无斜杠）
PUBLIC_SITE_URL=https://radminvpn.blog

# 根路径（默认 /）
PUBLIC_BASE_URL=/

# 搜索引擎所有权验证代码（选填，上线后直接注入公共 Head）
PUBLIC_GOOGLE_SITE_VERIFICATION=
PUBLIC_BING_SITE_VERIFICATION=
PUBLIC_SHENMA_SITE_VERIFICATION=
PUBLIC_BAIDU_SITE_VERIFICATION=

# 流量分析（选填）
PUBLIC_GOOGLEANALYTIC_ID=
```

## 🌐 生产部署建议 (Deployment)

由于本项目为 **100% 纯静态网站 (SSG)**，可极速零成本部署至全球主流静态托管网络：

### 推荐：Cloudflare Pages
1. 在 Cloudflare 控制台选择 **Workers & Pages** -> **创建应用程序** -> **Pages** -> **连接到 Git**；
2. 选择本仓库 `sksksk98698-source/radminvpn.blog`；
3. 构建预设选择 **Astro**：
   - 构建命令：`pnpm run build`
   - 输出目录：`dist`
4. 在 **自定义域** 中绑定正式主域名 `radminvpn.blog`；
5. 在 **重定向规则 (Redirect Rules)** 中配置将 `www.radminvpn.blog` 301 重定向至 `radminvpn.blog`。
