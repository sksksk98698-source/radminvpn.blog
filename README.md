## Key Features

- **SEO Optimized**: Complete OpenGraph, Twitter Card, Sitemap Index, and canonical URL structure.
- **Multi-language Support (i18n)**: Out-of-the-box support for English (`en`), Simplified Chinese (`zh-cn`), and Traditional Chinese (`zh-tw`).
- **High Performance**: Powered by Astro v7, Vite 8, and Tailwind CSS v4.
- **Offline Search**: Full-text client search powered by Pagefind.
- **Content Collections**: Type-safe Markdown and MDX content processing.

## Development

```bash
# 1. Install dependencies
pnpm install

# 2. Run local development server
pnpm dev

# 3. Build for production
pnpm build

# 4. Preview production build
pnpm preview
```

## Environment Variables

Configure `.env` for production deployments:

```ini
PUBLIC_SITE_URL=https://radminvpn.blog
PUBLIC_BASE_URL=/
PUBLIC_GOOGLEANALYTIC_ID=
```
